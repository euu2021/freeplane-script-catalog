## Monthly script scan: 2026-10

Decided by: Claude Code (claude-opus-5-5) applying tools/prompt.md by hand, since the proof-of-concept run had no API key.

7 posts carried code or a script file; 2 pointed to scripts already in the catalog; 4 were judged to share a script and are added below. Please check names, descriptions and tags before merging.

### Added

- **[UnifiedTagPanel (extended by aaa1386)](https://github.com/freeplane/freeplane/discussions/2953#discussioncomment-19172421)** by aaa1386 (script; tags, panel-gui): One overlay panel on the map that brings together Freeplane's three tag interfaces: the tag tree with usage counts, assigning tags, and managing tag categories. This version adds merge/assign, a fast add-child command, locating a tag, multi-tag selection with Shift/Ctrl and the arrow keys, and more colour options.
  - why: The reply publishes the full code of an extended version of the panel from the thread, ready to install.
- **[Floating zoom window](https://github.com/freeplane/freeplane/discussions/2995)** by Illegit (script; view, panel-gui): A small floating window with two buttons: one cycles the map zoom from 2x to 8x, the other restores the original zoom. Handy for inspecting one node in a big map. The window is resizable and remembers its position and size.
  - why: The opening post shares a complete script and explains what it does.
- **[Auto Deep Sort](https://github.com/freeplane/freeplane/issues/2901#issuecomment-6187762010)** by aaa1386 (script; editing, automation, dates-time): Keeps siblings sorted by when they were last edited: after you edit a node, it and each of its ancestors move up among their siblings, so recent work stays at the top all the way to the root. The ordering is kept in a JSON file next to the map.
  - why: The comment shares the full code of a script implementing the sorting requested in the issue.
- **[Smart Virtual Group Manager (GroupSiblingsNodes)](https://github.com/freeplane/freeplane/issues/2901#issuecomment-6187850379)** by aaa1386 (script; editing, navigation): Lets consecutive sibling nodes marked with an icon behave as one group: Alt+arrow keys on the first or last node move the whole group, and other nodes jump over it. Groups are created and removed from the context menu.
  - why: The comment shares the full code of a script with usage instructions.
